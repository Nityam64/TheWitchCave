# Hackolantern - The Witch's Potion Pantry (Track 01)

## Architecture
- `backend/`: FastAPI + Firebase Firestore (with in-memory fallback) + AI Engine (Prophecy Forecasting, Restock Spell, Strange Happenings Anomaly Detection, Midnight Curse 3x Festival Spike).
- `web-dashboard/`: React + Recharts + Vite B2B Dark Store Command Center with Manager Get Started launchpad & Crystal Ball curves, plus Hexley's Potion Pantry web client connected to Cloud Firestore.
- `android-app/`: Flutter Android client with Cleartext HTTP permissions, live LAN Wi-Fi / Tunnel IP switcher, and Shelf Audit barcode simulator.
- `firestore.rules`: Security rules requiring authentication and enforcing non-negative stock counts.

## Quick Run
Run all services with a single script:
```bash
./Hackolantern/start_all.sh
```

Or run services individually:
1. **Backend (Must bind to 0.0.0.0 so phones on Wi-Fi can connect):**
   ```bash
   cd Hackolantern/backend
   pip install -r requirements.txt
   uvicorn main:app --reload --host 0.0.0.0 --port 8000
   ```
2. **Web Dashboard:**
   ```bash
   cd Hackolantern/web-dashboard
   bun run dev   # or: npm install && npm run dev (or: python3 -m http.server 8000)
   ```
3. **Android Mobile App:**
   ```bash
   cd Hackolantern/android-app
   flutter run
   ```
   *Note:* The Flutter app features a top-right **⚙️ Server URL Settings** button to dynamically switch between your Laptop's Wi-Fi LAN IP (e.g., `http://192.168.88.35:8000`), Android Emulator (`http://10.0.2.2:8000`), or an Ngrok tunnel without needing to recompile the app.

## Data
In compliance with hackathon rules declaring all data assets used:
- **Synthetic Dataset**: Because no public data was provided by organisers, `backend/data/sample_sales_data.csv` is a realistic synthetic dataset generated by `backend/generate_dataset.py` with a fixed random seed (`SEED = 42`) for 100% reproducibility.
- **Contents**: Contains 90 days of daily sales history (2026-08-03 through 2026-10-31) across all 7 core potion ingredients with distinct baseline demands, weekly patterns (20–40% weekend surges), Poisson-distributed daily count noise, mild autumn upward trends, one historical festival (Full Moon Harvest Festival, Oct 4–6 with 3x demand spikes on 3 ingredients), and unlabelled consumption spikes.
- **Holdout Evaluation Set**: A 14-day future holdout dataset (`backend/data/holdout_future.csv`, 2026-11-01 to 2026-11-14) generated from the same underlying process serves as a hidden test set to benchmark out-of-sample forecast accuracy. It is never loaded into the application runtime.
- **Arbitrary CSV Ingestion**: The backend features an auto-detecting ingestion loader (`backend/data_loader.py`) capable of parsing unknown CSV formats—supporting long or wide layouts, diverse date formats, multiple daily transactions, and automatic 0-filling for missing days—via `POST /api/predict-csv`, `POST /api/evaluate-csv`, and `POST /api/score-csv`.
